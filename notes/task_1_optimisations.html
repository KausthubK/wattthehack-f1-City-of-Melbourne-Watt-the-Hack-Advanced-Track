  • Goal: reduce duck curve cost Started from Strategy scaffold and local objective scoring.
    • Rule-based candidate optimizer Candidate action search with local objective terms. This became the working base.
      • SOC reserve schedule Winner. Preserve midday solar energy and shape evening discharge.

        • Evening split: 0.20 until TOD 76, then 0.05 Improved $860,216.89 to $859,639.62.

      • Diesel candidates for peak shaving Rejected. Diesel cost outweighed demand-charge benefit.
      • Objective-weight tuning Small ties or tiny changes; no promoted gain once SOC target was fixed.
      • Action menu refinement Finer discharge steps and import-target candidates did not beat the current strategy.
    • Grid-charging arbitrage Rejected. Charging from grid increased import and carbon cost.

      • Rounds 2 and 3 skipped The base value function pointed the optimizer in the wrong direction, so follow-up rounds were not useful as originally planned.

Current Controller Logic Worth Keeping

Mechanic Current setting Purpose
Midday surplus reserve if 40 <= TOD <= 62 and solar > demand: return 1.00 Absorb as much free solar as possible before the evening peak.
Pre-peak reserve if 63 <= TOD <= 66: return 0.45 Prevent spending too early during the transition into peak.
Early evening reserve if 67 <= TOD <= 76: return 0.20 Keep enough battery for the late, more expensive peak.
Late evening reserve if 77 <= TOD <= 86: return 0.05 Allow stored energy to be spent when it matters most.
Diesel Only for grid-limit emergency Avoids blackout but does not use diesel for ordinary peak shaving.

What We Ignored Or Stopped

We deliberately avoided reading future scenario rows or hardcoding exact future demand/solar values. The public local data may differ from hidden judging data, so the promoted logic uses current state, time-of-day, and simple operational rules.

The experiments suggest that reaching about $800k would require a more structural controller than this rule-family. The obvious cheap extensions have been tested: grid charging, diesel shaving, value function, previous-day memory, and richer action candidates.
